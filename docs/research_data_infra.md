## 1. Real-Time & Historical U.S. Equity Market Data Providers

The single most important architectural fork in this category is **SIP (consolidated tape) vs. single-feed (IEX-only) data**. The SIP (Securities Information Processor) aggregates quotes/trades from all ~19 exchanges, dark pools, and FINRA TRFs, whereas IEX alone represents roughly 2–3% of consolidated volume. A scanner or alerting engine built on IEX-only data will miss the majority of prints and can show meaningfully stale/wrong prices during fast-moving small-cap or halt/resume situations — this is the central accuracy trade-off across every provider below.

## 2. SEC EDGAR: REST & Full-Text Search APIs

- **Rate limit:** SEC EDGAR enforces a hard **10 requests/second** ceiling across all automated access, monitored and enforced with HTTP 429 responses ([SEC — Accessing EDGAR Data](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data), [SEC Webmaster FAQ](https://www.sec.gov/os/webmaster-faq)).
- **User-Agent header is mandatory** on every request, in the format `Sample Company Name AdminContact@<domain>.com`. Missing or generic User-Agent strings return 403 "Undeclared Automated Tool" errors. No API key or authentication is required for any EDGAR API ([SEC Webmaster FAQ](https://www.sec.gov/os/webmaster-faq)).
- **REST endpoints** (all under `data.sec.gov`, JSON, no auth), documented at the [SEC EDGAR API documentation page](https://www.sec.gov/edgar/sec-api-documentation):
  - Submissions (current filing history, sub-second processing delay): `https://data.sec.gov/submissions/CIK##########.json`
  - XBRL Company Concept: `https://data.sec.gov/api/xbrl/companyconcept/CIK##########/us-gaap/{tag}.json`
  - XBRL Company Facts: `https://data.sec.gov/api/xbrl/companyfacts/CIK##########.json`
  - XBRL Frames: `https://data.sec.gov/api/xbrl/frames/us-gaap/{tag}/USD/CY2019Q1I.json`
  - Bulk nightly archives (`companyfacts.zip`, `submissions.zip`) under `sec.gov/Archives/edgar/daily-index/`, refreshed nightly ~3am ET.
- **Full-Text Search API** (functional, community-confirmed, not fully documented as a formal product page): `GET https://efts.sec.gov/LATEST/search-index?q=...&forms=8-K&startdt=YYYY-MM-DD&enddt=YYYY-MM-DD&ciks=...` — indexes all filings since 2001, fixed page size of 10 (paginate with `from=`), supports boolean AND/OR/NOT and exact-phrase quoting. Human-facing UI at [sec.gov/edgar/search](https://www.sec.gov/edgar/search/); background at the [SEC Webmaster FAQ](https://www.sec.gov/os/webmaster-faq); community documentation confirming endpoint behavior at [orthogonal.info](https://orthogonal.info/sec-edgar-full-text-search-api-efts-python/) and the [api-evangelist/sec-edgar GitHub repo](https://github.com/api-evangelist/sec-edgar).
- **Filing dissemination timing:** EDGAR accepts filings Monday–Friday, 6am–10pm ET; daily indexes refresh nightly around 10pm ET. Forms 3/4/5 (insider transactions) submitted after 10pm ET disseminate the next business day.
- **Catalyst-relevant filing types for a day-trading scanner** (all valid `forms=` filter values in full-text search): **8-K** (material corporate events — the primary catalyst filing), **S-1** (IPO registration statements), **424B** family, especially **424B5** (prospectus supplements — the mechanism by which ATM offerings and shelf drawdowns are disclosed), **SC 13D / SC 13G** (5%+ beneficial ownership stakes — activist/institutional catalysts), **Form 3/4/5** (insider transactions), and **S-3** (shelf registration statements, the parent filing that authorizes subsequent ATM programs).

### ATM / shelf-offering tracking in practice
There is no dedicated commercial API purpose-built for "ATM offering alerts." The authoritative and free approach is to monitor EDGAR full-text search filtered to `forms=S-3,424B5`. Example real filings confirm this pattern explicitly: a company enters an "At-The-Market Issuance Sales Agreement" and files a 424B5 prospectus supplement referencing its effective S-3 shelf, e.g. [Branchout Food Inc. 424B5, Jan 2026](https://www.sec.gov/Archives/edgar/data/1962481/000149315226003832/form424b5.htm), or a $3B forward-sale ATM program under an automatic shelf, e.g. [424B5, 2024](https://www.sec.gov/Archives/edgar/data/1032208/000119312524251695/d835130d424b5.htm). Commercial datasets that pre-parse this filing type exist, e.g. [SEC-API.io's Form 424B5 dataset](https://sec-api.io/datasets/form-424b5-content) (78,000+ filings since 1994), but the underlying source of truth remains free EDGAR full-text search.

## 4. Economic Calendars (FOMC, CPI, PPI, NFP, GDP)

- **FRED (Federal Reserve Bank of St. Louis):** REST API at `api.stlouisfed.org`, requires a free API key. Key endpoints: `fred/series`, `fred/series/observations`, `fred/series/search`. Docs: [FRED API documentation](https://fred.stlouisfed.org/docs/api/fred/) and [Federal Reserve Board's FRED user guide](https://www.federalreserve.gov/data/ddp-fred-user-guide.htm). Example CPI series page: [CPIAUCSL](https://fred.stlouisfed.org/series/CPIAUCSL).
- **BLS (Bureau of Labor Statistics):** Official release calendar covering CPI, PPI, and the Employment Situation (NFP) at [bls.gov/schedule](https://www.bls.gov/schedule/), with a subscribable `.ics` calendar feed. The [Employment Situation schedule page](https://www.bls.gov/schedule/news_release/empsit.htm) lists exact NFP release dates through November 2026, all released 8:30am ET, typically first Friday of the month.
- **BEA (Bureau of Economic Analysis):** GDP release schedule at [bea.gov/news/schedule](https://www.bea.gov/news/schedule) and the [full-year schedule](https://www.bea.gov/news/schedule/full). GDP is released in three estimates — Advance (~4 weeks post-quarter), Second (~8 weeks), Third (~12 weeks) — all at 8:30am ET. API registration at `apps.bea.gov/api/signup`.
- **Federal Reserve / FOMC:** Official meeting calendar at [federalreserve.gov/monetarypolicy/fomccalendars.htm](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm). Confirmed 2026 meeting dates: Jan 27–28, Mar 17–18, Apr 28–29, Jun 16–17, Jul 28–29, Sep 15–16, Oct 27–28, Dec 8–9. Blackout periods are also separately published by regional Fed banks, e.g. the [Chicago Fed's calendar page](https://www.chicagofed.org/utilities/about-us/federal-reserve-calendars).

## 5. Trading Halts

- **Nasdaq Trader:** Live halts page at [nasdaqtrader.com/trader.aspx?id=tradehalts](https://www.nasdaqtrader.com/trader.aspx?id=tradehalts); historical search at [tradinghaltsearch](https://www.nasdaqtrader.com/trader.aspx?id=tradinghaltsearch); and a **free RSS feed** updated once per minute at [TradeHaltRSS](https://www.nasdaqtrader.com/Trader.aspx?id=TradeHaltRSS) — explicitly documented as free and intended for programmatic polling, with guidance to query "not more than once a minute."
- **NYSE:** Live halts page at [nyse.com/trade/trading-halts](https://www.nyse.com/trade/trading-halts), with a **downloadable CSV** at [nyse.com/api/trade-halts/current/download](https://www.nyse.com/api/trade-halts/current/download) (columns: Halt Date, Halt Time, Symbol, Name, Exchange, Reason, Resume Date, Resume Time); one year of history available.
- **Halt reason codes** are standardized across the consolidated tape (CTA/UTP). Per [FINRA Notice 07-22](https://www.finra.org/rules-guidance/notices/07-22) and normalization references such as [Algoseek's halt code documentation](https://algoseek.com/data-sets/docs/eq_trading_halts): **T1** (news pending), **T2/T3** (news released), **T5** (single-stock volatility, >30% move in 5 min), **T6/H10/H11** (regulatory), **T12** (information requested), **LUDP/LUDS** (Limit-Up/Limit-Down pause/straddle — the most common halt type, a 5-minute auto-pause on band breach), **MWC1/2/3** (market-wide circuit breakers at S&P 500 declines of 7%/13%/20%), and **IPO1/IPOQ/IPOE** (new issue not yet trading).
- **Programmatic consumption patterns:** polling the free Nasdaq RSS feed (once/minute), pulling the NYSE CSV on a schedule, or using third-party normalized APIs such as [Algoseek's Trading Halts REST endpoint](https://algoseek.com/docs/rest-api/reference/endpoint-v-1-data-us-equity-ref-trading-halts-get) or [Unusual Whales' halts API](https://unusualwhales.com/trading-halts) (docs at `api.unusualwhales.com/docs`).

## 8. API Licensing, Rate-Limit & Redistribution Gotchas

A solo developer building a **personal, non-redistributed** tool sits in a materially different regulatory position than someone shipping a public product, and the difference is almost entirely about SIP/exchange licensing:

- **OPRA (Options Price Reporting Authority) fees:** Professional Subscriber Device-Based Fee $31.50/device/month (2018 rate); Nonprofessional Subscriber Fee on a sliding scale from $1.25 down to $0.60/subscriber at high volume; usage-based alternative of $0.0075/quote packet or $0.03/options chain ([OPRA fee schedule PDF](https://cdn.opraplan.com/documents/OPRA_Fee_Schedule.pdf)). A Redistributor License runs approximately $1,500/month (or $650/month query-only) per a third-party guide ([ThetaData's OPRA fee guide](https://www.thetadata.net/articles/2026-05-29-opra-fee-guide-for-options-market-data)).
- **UTP Plan (Nasdaq-listed data) fees:** Professional subscriber $24/month + $0.0075/query; Nonprofessional subscriber $1/month; Nonprofessional Enterprise Cap of $648,000/month/firm for broker-dealers ([UTP Plan data policies PDF](https://www.utpplan.com/DOC/datapolicies.pdf)).
- **Real-world illustration — Interactive Brokers' market-data pricing page** shows the professional/non-professional gap concretely: NYSE (Network A/CTA) Level 1 is $1.50/month non-professional vs. $45/month professional; Nasdaq (Network C/UTP) Level 1 is $1.50 non-pro vs. $25 pro; OPRA Level 1 is $1.50 non-pro vs. $32.75 pro ([Interactive Brokers market data pricing](https://www.interactivebrokers.com/en/pricing/market-data-pricing.php)). "Non-professional" essentially means personal, non-business-use — exactly the profile of a solo retail developer's personal tool.
- **CTA (Consolidated Tape Association) redistribution:** Any entity that redistributes CTA data to another entity or person must sign a Consolidated Vendor Form (Exhibit C) and be approved by the network administrator; flat redistribution charges apply. See the [CTA Plan document](https://www.nyse.com/publicdocs/ctaplan/notifications/trader-update/CTA_Plan_Composite_as_of_September_1_2015.pdf) and [ctaplan.com](https://www.ctaplan.com/).
- **IEX Exchange direct fees** (if bypassing a reseller): DEEP $2,500/month, TOPS $500/month, DEEP+ $3,500/month for real-time; delayed versions are free ([IEX fee schedule](https://www.iex.io/resources/trading/fee-schedule)).
- **The practical takeaway for a bootstrapped solo developer:** going direct to a SIP or exchange requires signing vendor/redistribution agreements and reporting professional vs. non-professional subscriber counts — overhead that is not worth it for a single personal user. Using a reseller that has already negotiated this licensing (Alpaca, Massive/Polygon, Finnhub, Twelve Data, Databento) is dramatically simpler: the reseller absorbs the SIP/exchange licensing complexity into its subscription fee, and personal, single-user, non-redistributed use typically falls under a "Personal Use" developer license — e.g. Finnhub's free tier is explicitly labeled **"Personal Use"** ([Finnhub pricing](https://finnhub.io/pricing)), and Alpaca's brokerage-integrated model similarly targets individual account holders rather than data redistributors ([Alpaca market data docs](https://docs.alpaca.markets/us/docs/real-time-stock-pricing-data)).

## 5-Bullet Summary for Architecture Decisions

- **Recommended primary market-data provider: Alpaca (Algo Trader Plus, $99/month).** It is the only provider in this comparison offering **true SIP/consolidated-tape coverage** at a genuinely bootstrapped price point ($99/mo vs. Massive's $199/mo Advanced tier or Databento's $1,750+/mo institutional tiers), with a native real-time WebSocket API, unlimited symbol streaming, built-in Corporate Actions and halt/LULD status channels, and brokerage integration for execution in the same account — eliminating a second vendor relationship entirely ([Alpaca pricing](https://alpaca.markets/data), [real-time docs](https://docs.alpaca.markets/us/docs/real-time-stock-pricing-data)).
- **Runner-up worth weighing: Massive (formerly Polygon.io) at $29–79/month** if SEC-filing-derived signals (8-K text, Form 3/4, 13-F) and flexible custom-interval historical bars (e.g., 5-minute pre/post-market bars) matter more than brokerage integration — it also offers the cleanest low-cost path to Benzinga news via its $99/month add-on ([Massive pricing](https://polygon.io/pricing), [corporate actions docs](https://massive.com/docs/rest/stocks/corporate-actions/splits)).
- **Do not build on IEX Cloud** — it was discontinued as a product on August 31, 2024; any 2026 architecture referencing it is working from stale information ([IEX Cloud closure notice](https://iexcloud.org/)).
- **Recommended primary news source: Benzinga**, starting on its free AWS Marketplace tier and upgrading to the ~$99–166/month tier (direct or via Massive/Polygon) once volume justifies it — it is the only option offering both a genuinely free entry point and sub-100ms real-time delivery claims, unlike StockTwits (too noisy, no history), MT Newswires (enterprise-only, ~$4,000/month), and NewsAPI.org (free tier is 24-hour delayed and explicitly non-commercial; cheapest usable tier is $449/month) ([Benzinga APIs](https://www.benzinga.com/apis/), [AWS Marketplace free tier](https://aws.amazon.com/marketplace/pp/prodview-xwgvhwowjmw3g), [NewsAPI.org pricing](https://newsapi.org/pricing)).
- **Free-tier data feed choice is a real accuracy risk, not just a cost trade-off** — SEC EDGAR (rate-limited to 10 req/sec, requiring a proper User-Agent header) and the Nasdaq/NYSE halt feeds are free and sufficient for catalysts and halts respectively, but any scanner logic built on IEX-only quotes (Alpaca free, and likely other free tiers) should be treated as directionally useful only, not execution-grade, until upgraded to a SIP-inclusive plan ([SEC EDGAR access policy](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data), [Nasdaq Trader halts RSS](https://www.nasdaqtrader.com/Trader.aspx?id=TradeHaltRSS)).
